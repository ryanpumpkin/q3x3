# 九方 W10 重建版（第二版）

Windows x64 浮動輸入面板，按原裝九方 W10 專業版 1.1.0.0 嘅 `q9w10b5tsf64.dll` 反編譯結果重寫。repo 本身唔附帶任何原版資料：程式由原裝 DLL 讀碼表、由 `SKINready` 讀皮膚，呢啲檔案要嚟自本機已安裝嘅原版 `C:\Program Files\Q9W10B5`，可以喺執行時讀，或者喺編譯時內置入 exe。`big5hkscs.map` 係公開標準嘅 Big5-HKSCS 對照表，編譯時已經內置；如果 exe 旁邊有呢個檔案，就會優先用嗰份。

## 內置原版資料（唔使再裝原版）

```powershell
.\build.ps1 -Embed                                # 由 C:\Program Files\Q9W10B5 讀
.\build.ps1 -Embed -Install D:\backup\Q9W10B5     # 由其他位置讀
```

編譯時會核對原裝 DLL 嘅 SHA-256，然後將 `q9w10b5tsf64.dll`、所有大小嘅 `SKINready\default\*\normal` 皮膚、`B5_`／`GB_` 自定範本同 `q9help.chm` 內置入 `Q9Rebuild.exe`（約 37 MB）。之後淨係呢個 exe 就行到，唔使原版資料夾，亦唔使另外放 `big5hkscs.map`。執行時每個檔案都會先搵內置版本，冇先讀安裝目錄。說明書同自定範本會解壓到 `%APPDATA%\Q9Rebuild\original\`。

**呢個 exe 包含九方原版嘅版權資料，只可以自己用，唔好放上 GitHub Releases 或者公開分享。** `.gitignore` 已經排除 `*.exe`。

## 使用

開 `Q9Rebuild.exe`，面板出現喺螢幕右下角。喺要打字嘅程式放好游標，用數字鍵盤（開 NumLock）輸入。

### 裝入 Windows 輸入法清單

用 `.\build.ps1 -Setup` 產生 `Q9Setup.exe`。喺有原版九方 W10 嘅電腦執行安裝檔並完成 Windows 管理員確認，就可以喺繁體中文輸入法清單揀「九方 W10 重建版」。安裝時會登記 32 位元同 64 位元 TSF。解除安裝可經「已安裝的應用程式」進行。

TSF 版本由 Windows 將按鍵送到九方，再經編輯工作階段寫入應用程式。直接開 `Q9Rebuild.exe` 仍然可以用獨立浮動面板。實機登記同應用程式相容性嘅驗證狀態見 [TSF-PLAN.md](TSF-PLAN.md)。

| 鍵 | 作用 |
| --- | --- |
| 1–9 | 取碼；選字時揀對應方位嘅字 |
| 0 | 選字／下頁；有關聯字時先揀關聯字，冇就入標點 |
| . | 取消；有關聯字時喺靜止狀態入標點 |
| - | 上頁；筆劃／字形第一頁開字形檢字；靜止時開「自定常用」 |
| + | 筆劃／字形取碼或選字時開補音／姓氏；其他選字頁下頁；靜止時開「詞輸入」 |
| / | 輪流切換輸入法：筆劃 → 字形 → 拼音 → 注音 → 粵拼 → 數字 → 表情符號（同原版次序）；頂排輸入法掣一樣，掣上面顯示嘅係「下一個」輸入法 |
| * | 面板轉去右上角／右下角 |
| Backspace、Esc | 取碼中退一碼／取消 |
| 快按 Shift | 暫時隱藏／重現面板，隱藏時數字鍵盤照常打數字 |

滑鼠可以直接點九宮格、「取消」、右邊「−／+」掣同頂排按鈕。點格仔左上角嘅細字會直接上字。左上角「九方 W10」或者右鍵開設定選單。

## 已重建

- **九方筆劃**：鍵位轉換（7 8 9 = 橫豎撇）、一至三碼、每一步嘅左上角候選、第二碼部件底圖、基本筆劃嘅 4 個最近用字、上文預測（同碼關聯字插入第一頁）、「有部首用部首」碼表切換。
- **九方字形**：字首特徵 → 部件 → 確定／右字首。第一碼後按 0 可揀姓氏，字形及補音篩選讀原版分類資料。
- **九方拼音**：聲母鍵（電話鍵盤排法，7 鍵冇字母）→ 單韻母 → 複韻母（0 = 確定）→ 常用音節先揀聲調（7 一聲、9 二聲、3 三聲、1 四聲、0 其他），其他音節直接出字。冇聲母時按韻母所在嘅鍵再按 0，a／e／o 單字會直接排喺空格。聲母後按四角（1 3 7 9）出標點同符號。
- **九方注音**：聲母（0 = 冇聲母）→ 韻母直接出字，或者先揀介音 ㄧㄨㄩ 再揀韻母。冇聲母時再按 0 開「選檢字方法」。同原版一樣只喺繁體模式提供。
- **罕用字顯示**：正黑體／雅黑冇嘅 CJK 擴展字同香港字，會自動改用細明體_HKSCS、細明體_HKSCS-ExtB、新宋體-ExtB 等系統字體顯示。已逐隻檢查過全部碼表，本機字體可以顯示晒。
- **九方粵拼**：逐個字母按鍵，面板顯示所有可能嘅拼法，＋／－ 揀拼法，0 選字。同原版一樣只喺繁體模式提供；可開「輸出簡體字」轉換上屏文字。
- **選字**：九格按數字鍵盤方位排，候選字由「1」鍵（左下）開始放，唔夠九個嘅空格灰色。按 0 下頁。
- **關聯字**：預設係原版嘅動態關聯字，直接讀你喺原版學返嘅 `%APPDATA%\q9\Q9W10\q9data\B5_q9b5rel.tbl`，次序同原版一樣（第 9 格固定「的」）；喺重建版用過嘅組合另外記錄，唔會改原版檔案。另有固定、固定＋自定、關閉三種。
- **資料視窗**：上字之後顯示筆劃碼、字形碼、拼音、劃數、內碼、倉頡（原版 INFODATA）；取碼時顯示同原版一樣嘅步驟提示，冇字時顯示「未有字」畫面。
- **原版版面**：照原版截圖逐像素對過，格線用 `Button09Transparent.png`、格仔底色用皮膚檔 `kFillBlankColor`，字用 GDI 細明體_HKSCS（大字 ClearType、資料視窗 14px 點陣字），位置全部按皮膚檔 `TextAdjust*`、`CellSize` 等數值計；選字格四角灰三角、0 行「選字／標點／姓氏／確定／下頁」標籤、右邊「自定常用／詞輸入／字形檢字／上頁」掣都跟原版逐個狀態切換。
- **標點、符號同檢字**：八個常用標點直接上屏；按 0 開完整符號表，按 9「其他」開「選檢字方法」。用原版碼表按總筆劃、部首或符號分類揀字。「音」開獨立檢字視窗，可輸入普通話拼音或粵拼查字。
- **詞語／自定短句視窗**：先列自定詞語，再列原版繁簡內置詞庫。已有前字時可以依詞長篩選。喺靜止面板撳 `+`，如剪貼簿有符合條件嘅文字，會先顯示「增加詞組」確認。
- **選字格四角功能**：有字資料、發音、近音、詞庫同字典入口。粵語用原版隨附音檔，普通話用本機語音。字典入口包括已安裝嘅九方漢語字典同網上字典。
- **查（見字查字）**：先喺程式選取文字，再撳面板頂嘅「查」。輸入法版經 TSF 直接讀選取文字，浮動面板版用 Ctrl+C 讀完再還原剪貼簿。選單有：
  - 中英文字典同網上搜尋（Google、Yahoo、百度、維基百科、開飯、黃頁、報章、Facebook、Youtube、拍賣）。原版經九方伺服器轉駁，重建版直接開公開網站。
  - 選取一個中文字時：粵語／普通話發音、資料・發音・近音、詞庫功能、部首筆劃查字。
  - 數字對譯：將選取咗嘅數字換成英文、中文小寫、大楷或者全形數字（右鍵「數字對譯形式」揀格式）。
  - 英文對譯中文：用瀏覽器開 Google 翻譯。
  - 中英文地址互查：用香港政府地址查詢服務（www.als.gov.hk）搵中英文地址，可以直接輸入或者開 Google 地圖。
  - 選單項目、次序同字眼照原版 W10 截圖（反白「細哥」之後撳查）。原版所有項目都可以撳，唔啱用嘅就響一聲。
- **自定常用**：靜止時撳「−」開獨立「自設常用字句 / 符號」視窗（同詞語視窗一樣嘅外觀），編輯會開 `yourAlwaysUse.txt`。
- **輸入過嘅字自動調前**：重建版將調整後嘅碼表保存喺自己嘅設定目錄。
- **表情符號、數字模式**。
- **繁簡**：繁體／簡體碼表切換，同埋輸出時繁簡互換。
- **自定檔案**：詞語／自定短句、自定常用、自定關聯字，用記事本編輯。
- **設定**：視窗大小 200–1000、靜止透明度、四種鍵盤輸入鍵（數字鍵盤開／關 NumLock、文字鍵、上排數字鍵）、輸入記錄。

## 未重建

- 可切換嘅補音分類：W10 嘅右鍵選單冇呢項（只係舊版說明書截圖有「發音／同音字／拼音檢字」選單），截圖冇講每項做咩，所以冇做。
- 自定常用視窗開咗時，原版面板保持靜止畫面；重建版面板仍然顯示嗰頁字句。
- 其他外觀樣式（淨係用 `default`）。

## 同原版可能有出入嘅地方

以下幾項係按反編譯結果推斷，未同原版逐鍵對照：

- 選完關聯字頁之後再按 0 會入標點頁。
- 上文預測只做第一頁（最多 3 個）。
- 取碼中「−／+」掣顯示嘅圖片，同埋第三碼嘅底圖。
- 拼音、注音嘅滑鼠路徑：原版用滑鼠點時有另一套流程（例如注音會問聲調），重建版滑鼠同鍵盤一樣。
- 拼音輸入時原版會預覽候選字，重建版冇做。
- 筆劃第二碼、注音介音之後、粵拼靜止時嘅提示字係推斷，未截到原版畫面。

## 資料同設定位置

- `%APPDATA%\Q9Rebuild\`：設定、最近用字、動態關聯字、輸入記錄、你編輯過嘅自定檔案。最近用字同學到嘅關聯字記錄喺 `state.txt`：有改動就每 30 秒寫入一次，關面板時再寫一次；用暫存檔換入，程式死咗最多只會冇咗半分鐘嘅記錄，唔會整壞個檔。
- 原版 `%APPDATA%\q9\Q9W10\q9data\` 只會讀取，唔會改動。

## 編譯同驗證

```powershell
.\build.ps1
(Start-Process .\Q9Rebuild.exe -ArgumentList '--self-test' -Wait -PassThru).ExitCode
(Start-Process .\Q9Rebuild.exe -ArgumentList '--test-input' -Wait -PassThru).ExitCode
(Start-Process .\Q9Rebuild.exe -ArgumentList '--test-hook' -Wait -PassThru).ExitCode
```

三項成功都返回 0。`--self-test` 用說明書嘅字例核對引擎（志 71、碼 797、入 94、九 270、快 892、中 810；拼音 雙、時、安、啊；注音 西、找；粵拼 陳；關聯字、標點、繁簡、表情符號）。`--test-input` 經面板按鍵處理送字，`--test-hook` 經數字鍵盤攔截送字；兩者都核對 Windows 測試文字框收到「走」「修」「雙」「西」「人」同「😃」。兩個測試都需要測試視窗攞到前景。

## 自動對照原版截圖

用原版同一個皮膚、面板大小、繁簡設定同輸入狀態截一張無縮放 PNG。以下用粵拼 `303` 上「人」後嘅關聯字頁，假設原版面板左上角係截圖嘅 `(428, 167)`，底部只見到 475 像素高。若原版 PNG 已裁成完整面板，可以省略 `-X`、`-Y` 同 `-Height`。

```powershell
.\check-parity.ps1 -Reference C:\path\to\original.png -Keys C303 -Size 300 -X 428 -Y 167 -Height 475
```

`-Keys` 用 `S/G/P/Z/C` 揀筆劃、字形、拼音、注音、粵拼，後面寫數字鍵盤按鍵，`b` 代表退格。檢查器會喺獨立測試程序重播按鍵，列出上屏文字、九格候選、字資料同分區像素差異，並喺 `preview/parity/` 輸出裁好嘅參考圖、重建圖同差異圖。紫紅色表示最少一個 RGB 色階偏差大過 `-Tolerance`（預設 2，用 0 可逐像素精確比較）。退出碼 0 表示全部像素喺容許範圍，1 表示有差異，2 表示檢查出錯。關聯字次序仍會受本機原版已學習嘅資料影響。
