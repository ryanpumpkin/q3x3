# 同原版對比測試紀錄

原版：九方 W10 專業版 1.1.0.0（`q9w10b5tsf64.dll`，SHA-256 `02755c6a…`），皮膚 `default`，面板大細 300。
分支：`parity-rea`。最後更新：2026-11-18。

## 點樣測試

1. 喺記事本揀原版九方，用 SendInput 送數字鍵盤鍵（`q9cap keys`）。
2. 用 `PrintWindow` 截原版面板（視窗 class `imeq9w10win`）。用 PrintWindow 係因為螢幕截圖會截埋 Claude 控制畫面時嘅覆蓋色。
3. `ComparePanel.exe` 用同一串鍵喺重建版重播，逐像素比較四個區域：工具列、九格、兩邊掣同皮膚、資料區。每個顏色通道容許相差 2。
4. 批量測試（`batch.ps1`）會逐個碼做完上面三步，然後撳「.」取消，返去靜止狀態。全程唔會上字，所以唔會改到原版嘅自動調前資料。

重建版同原版讀同一份碼表：先讀 `%APPDATA%\q9\Q9W10\q9data`，冇先讀 DLL 資源。所以測試比較嘅係處理邏輯，即係轉碼、分頁、未有字、檢字等，唔係比較碼表內容。

字形批量測試第一次跑有 26 個唔同，全部改好咗（commit `6a880f6`）：

- **三碼冇字：** 原版入「未有字」畫面，碼同關聯字都清咗，下一個鍵當重新開始。
- **字形撳 0：** 原版睇上一個候選字清單停喺第幾頁（FUN_1800ad920）。
  - 喺第一頁：出「檢字」款標點頁，嗰頁再撳 0 開檢字選單，取碼時「−」掣係「字形檢字」。
  - 唔係第一頁：出「下頁」款標點頁，嗰頁再撳 0 開符號頁，取碼時「−」掣係「上頁」。
- **HKSCS 擴展字：** 原版用 MAPBU 資源轉碼（由 0x8840 起，每行 158 格）。
  - 轉唔到嘅碼（0x81–0x87 開頭嘅全部，另外 66 個）只係留空格，但係仍然佔一個候選位，照畫選字三角形。
  - 重建版揀呢啲格會嗶一聲，唔會上字。原版揀呢啲格會點，未試過。

筆劃批量測試第一次跑有 34 個唔同。腳本修正後重跑，再改咗以下四樣：

- **測試腳本：** 有啲序列會自動上字，返去關聯字頁，之後腳本再撳「.」就會開標點頁，下一個序列唔同步。而家返咗靜止頁就唔撳「.」。
- **預覽字顏色：** 原版預覽字一律用 0xd52880 紫色。重建版之前將擴展字畫成紅色，例如「凤」。
- **未有字畫面：** 原版唔畫預覽字。筆劃時 0 鍵係「選字」，因為之前嘅碼仲有字。
- **筆劃未有字之後：** 原版候選數當 0（FUN_1800bf390 param_7）。
  - 撳數字：由嗰一筆重新開始，例如 243 再撳 1，出艹頭字。
  - 撳 0：揀預設關聯字（你這好到資就個能的）。

拼音、注音、粵拼修正咗：

- **轉碼：** Big5 0x8840 以上一律先查 MAPBU；查到私用區字元，先用 HKSCS 表攞真正嘅 Unicode。之前有 255 個符號轉錯，例如 A242 應該係 U+FE68。
- **未有字之後：** 拼音、注音同字形一樣，下一個鍵當重新開始。
  - 粵拼字母鍵：由呢個字母重新開始。
  - 粵拼撳 0：停喺未有字，0 鍵變「選字」，加三行提示。
- **未有字畫面：** 拼音、注音有三行提示，注音 0 鍵係「韻母」，拼音唔畫灰格。粵拼唔畫拼法清單。
- **粵拼冇呢個拼法：** 入未有字，唔再顯示「沒有這個拼音」。
- **拼音四角符號頁：** 冇選字三角形。
- **拼音冇聲母直接揀字：** 嗰幾格畫三角形。
- **上咗符號之後：** 保留上一隻字嘅關聯字頁；未有嘅話就顯示預設字，唔對調上下行。資料區留空。

剩低嘅 6 張：

- **關聯字資料變動（4641、4741、457500、96750、649700）：** 測試途中原版自動上字，學咗新嘅關聯字，例如「穫」多咗「勘」。原版會改寫 q9b5rel，但係重建版讀嘅係之前嘅檔案。
- **重播由頭開始（7997）：** 原版只會喺之前出過關聯字之後，先用預設字補一隻冇關聯字嘅字，但係重建版每次重播都係全新開始。

修正咗：

- **補音頁：** 用 PYREL 圖，預覽 0 鍵嗰組字嘅第一頁，0 鍵係「選字」。
- **補形頁：** 0 鍵係「選字」，提示照用補音嗰兩行；撳 0 冇字就入未有字，兩邊用預設掣。
- **補形、補音揀完嘅清單：** 兩邊用預設掣。

## 已知差異（未修好）

- **資料區廣告：** 原版靜止時資料區會輪流顯示廣告，重建版冇做。
- **粵拼資料區：** 已按原版程式改用白色全形「－」「＋」，按仲有冇上一個／下一個拼法顯示。三行清單會跟住揀中嘅拼法捲動。仍待用原版取碼截圖重做像素對照。
- **原版舊頁數：** 原版嘅頁數記錄冇清嘅話，字形第一碼「−」掣會顯示「上頁」。重建版有模擬呢個規則，但係單獨重播一串鍵時，冇辦法重現原版之前翻過頁嘅狀態。
- **取碼時「−」掣：** 原版用 FUN_1800ad920 嘅頁數記錄決定顯示「字形檢字」定「上頁」。有一個情況未搞清楚：同樣喺第三頁撳「.」取消，兩次結果唔同，同之前有冇撳過「−」翻頁有關。
  - 反編譯結果（2026-11-18）：清單結構 +0x40／+0x50 係「最後攞過嗰頁」喺碼表資料區嘅開始同結束位元組位置。FUN_1800ad560 第一頁（模式 1）先清做 0 再攞；下頁（模式 3）由結束位置向後攞；上頁（模式 2）由開始位置向前攞；攞到 0 個字（或者成頁都係空白字 0x40a1／0xa1a1／0x3000，FUN_1800aeeb0）就唔改位置。第一頁撳「−」（FUN_1800ad6c0 參數 2）會一頁頁向後攞，直到攞唔到為止，所以位置停喺最後一頁。
  - 判斷（FUN_1800ad920）：碼要數字開頭、長度 > 0；+0x40 係 0 就係「字形檢字」；否則 `((開始 + 結束) / 2 − 現時碼喺索引嘅開始 × 2) / 18 == 0`（FUN_1800bc5d0 讀碼表索引）先係「字形檢字」，其餘係「上頁」。即係比較「上一個清單停喺邊度」同「而家打緊嘅碼喺碼表邊度」，唔係比較頁數。
  - 未知：上字之後邊度清咗 +0x40。如果冇清，打新碼第一碼幾乎一定係「上頁」，同原版截圖唔符，所以上字（或者之後載入關聯字）應該有清或者改寫，但靜態睇唔出。重建版暫時保留「上一個碼清單停喺第一頁」嘅近似。要定案可以喺原版逐組試：(1) `711` 揀字後打 `9`；(2) `711` 撳 0 去第二頁、撳「.」取消、打 `9`；(3) `711` 撳「−」去最後一頁、撳「.」取消、打 `9`；(4) `711` 撳 0 去第二頁、撳「.」取消、再打 `711` 嘅第一碼 `7`。每組記低「−」掣顯示咩。

## 後續驗證

- 繁體部首頁改用原版 DLL 嘅 37 個黑白點陣字。將每個字按九種字號繪製，333 個結果同原版 GDI 繪製途徑逐像素一致。簡體部首頁改用原版 225 項簡體編碼部首陣列，已驗證繁簡第一筆第一頁同「土」部字表。
- 原版同重建版嘅字形 `9890` 第二頁，九格候選同次序一致。重建版經數字鍵盤攔截重播 `98901`，Windows 測試文字框收到「修」。
- 原版筆劃 `710+` 補音預覽同 `710+0` 選字頁，九格候選同重建版一致。
- 原版字形 `892-0` 同筆劃 `17-5` 嘅補形「未有字」頁，按退格會留喺原畫面。重建版之前會因為空碼而崩潰，已修正，兩條序列都加咗入自測。筆劃補形「未有字」頁嘅 0 鍵亦已改為顯示「選字」。
- 重建版用預設皮膚喺 200 至 1000 九種尺寸繪製 1,350 個測試畫面，涵蓋繁簡可用模式、輸入同選字狀態。另用固定種子 9918 重播 26,924 下隨機按鍵，包括退格、標點、補碼同翻頁，全部通過。
- 首次重跑至 1000 尺寸時，繁體筆劃 `7` 嘅最近用字同 200 尺寸基準有出入。原版實機測試揀「袁」後，更新咗 `B5_q9sdyd.bin`，而測試每換一個尺寸會重新讀取該檔。固定最近用字快照後，繁體同簡體嘅 `7` 候選各自喺九種尺寸完全一致。
- 原版嘗試喺記事本選「修」（`98901`）同「袁」（筆劃 `710+05`）時彈試用提示。關閉提示後重試，記事本仍然空白。按「否」會開註冊授權視窗，亦未見文字送到記事本。
- 原版同重建版都喺記事本實際上字。兩版各自重播筆劃 `7105`、字形 `98901`、拼音 `1651`、注音 `3703`、粵拼 `303` 同表情符號 `11`，分別得到「走」「修」「雙」「西」「人」「😃」。重建版測試程序沿用面板同鍵盤攔截，開啟診斷用嘅模擬按鍵接收，並用獨立設定目錄。
- `--test-input` 同 `--test-hook` 亦各自喺 Windows 測試文字框驗證上述六組實際輸出。
- 舊嘅 300 尺寸粵拼 `303` 截圖，工具列喺 RGB 容差 2 內完全相同。將重建畫面嘅 0 鍵行同資料區向上對齊一像素後，分別剩 0 同 4 個不同像素。呢個對齊只用嚟定位差異，冇改全局座標。
